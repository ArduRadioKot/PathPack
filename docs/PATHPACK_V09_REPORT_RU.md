# PathPack v0.9: три гипотезы, v0.4 остаётся базой

Дата: 2 ноября 2026. v0.4, v0.5, v0.5.1, v0.6, v0.7 и v0.8 не менялись. Их прогоны не перезаписывались. Счётчик токенов прежний: `utf8_bytes_div4_ceil_serialized_context_v1`. Конфиги записаны до соответствующих прогонов и после чисел не менялись. Holdout не запускался: ни одна конфигурация не обошла v0.4 по всем четырём метрикам, а снимки 60 задач holdout не развёрнуты.

Цели при 2048 токенах (File ≥ 0.800, Function ≥ 0.280, Complete ≥ 0.150, Changed Line ≥ 0.220) не достигнуты. Это не результат, который можно объявить успехом.

## Диагноз v0.4 при 2048

Прокси по сохранённому пулу v0.4 (`output/v09_dev/error_diagnosis.json`). File Recall 0.725 держится на коротком первом чанке и штрафе за повтор файла. Changed Line Recall плоский от 1024 до 4096: найденные строки уже лежат в первой тысяче токенов. Повторная укладка того же пула (один чанк на файл, круговая очередь, жадный добор новых строк) не поднимает File Recall ни на одной из 20 задач. Пропущенный файл стоит в порядке позже, чем позволяют токены открывающих чанков.

Ошибки делятся так.

Поиск, чанк не вошёл в пул 512:

- `sympy__sympy-21379`, `sympy/core/mod.py`. Лучший lexical 0.350, в графе глубины 2 от семян вес 0, причина `candidate_limit`. Упаковка этот файл не достанет.

Упаковка, файл уже в пуле, но после бюджета:

- `django__django-14725`, `django/forms/models.py`, порядок 21, lexical 0.683.
- `mwaskom__seaborn-3187`, `seaborn/_core/scales.py`, порядок 27, lexical 0.513.
- `scikit-learn__scikit-learn-9288`, `sklearn/cluster/k_means_.py`, порядок 64.
- `django__django-14580`, `django/db/migrations/serializer.py`, порядок 72.
- `pydata__xarray-6599`, `xarray/core/computation.py`, порядок 103. Впереди короткие чанки `print_versions.py` с graph 0.8.

Функция нужного файла есть в пуле и не помещается: `sphinx` `check`, `pytest` `visit`, `sympy` `UnitSystem._collect_factor_and_dimension` (покрытие тела 0.159, порог 0.20), `requests` `build_digest_header`. Символьный признак v0.4 делит совпадение имени на длину всего текста задачи, поэтому имя `polyval` или `fromstring` почти ничего не весит рядом с коротким соседом по графу.

## Журнал

Один и тот же dev-набор, 20 задач, бюджеты 1024, 2048, 4096, парный bootstrap 2000, seed 42. Аудит бюджета, интервалов и вложенности префиксов на всех трёх прогонах прошёл без нарушений. `plain` (пул без потолка, бонус 0, имя 0) совпадает с `pathpack-v4` на всех 20 задачах и всех трёх бюджетах.

### 1. Потолок пула и бонус покрытия

Конфиг `configs/pathpack_v09.yaml`. Прогон `output/v09_dev`. Не больше 8 чанков файла в пуле 512. К оценке прибавляется `0.25 * (новые строки функции / длина функции + пересечение 20% и 100%)`.

Парные разности v9 − v4 при 2048: File −0.400, 95% CI [−0.625, −0.150], 1/9/10. Function −0.119 [−0.286, 0.000], 0/15/3. Complete −0.008 [−0.024, 0.000], 0/17/1. Changed line −0.077 [−0.224, 0.000], 0/12/2.

Причина: бонус получает уже первый чанк, если он покрывает 20% короткой функции. Прибавка доходит до 0.75 и перевешивает и lexical, и штраф за повтор файла. Потолок пула здесь ни при чём: `no-coverage` при 2048 совпадает с v0.4 по всем четырём метрикам. При 4096 тот же потолок поднимает Function до 0.258 и Changed line до 0.243, но File падает с 0.800 до 0.775, а интервалы прироста включают 0. Это не замена базы.

### 2. Редкое имя в оценке

Конфиг `configs/pathpack_v09_name.yaml`. Прогон `output/v09_name_dev`. Потолок и бонус выключены. Если идентификатор из квалифицированного имени (не короче 5 символов, не чаще чем у `max(3, 1%)` функций, `KMeans` и `k_means` сходятся к `kmeans`) встречается в тексте задачи, к оценке прибавляется 0.55. Величина выбрана до прогона так, чтобы чанк около 200 токенов с полным совпадением имени сравнился по полезности с коротким чанком graph 0.8.

При 2048:

| Метод | File | Function | Complete | Changed line | Latency, с |
| --- | ---: | ---: | ---: | ---: | ---: |
| pathpack-v4 | 0.725 | 0.202 | 0.091 | 0.148 | 0.579 |
| pathpack-v9 | 0.950 | 0.202 | 0.147 | 0.095 | 0.579 |

File +0.225, CI [0.075, 0.400], 5/15/0, ноль не входит. Выигрыши: `django-14580`, `django-14725`, `seaborn-3187`, `xarray-6599`, `sklearn-9288`. Function 0, CI [−0.167, 0.167], 1/16/1: потерян `pylint/__init__.py::modify_sys_path`, найден `requests/sessions.py::merge_setting`. Complete +0.056, CI [0.000, 0.167], 1/17/0, ноль входит. Changed line −0.053, CI [−0.219, 0.061], 1/11/2: `pylint-7277` 1→0 и `sympy-13878` 0.071→0, против `sklearn-13124` 0→0.333.

Имя поднимает нужные файлы, но совпадений сотни: у Django около 100 файлов получают тот же бонус. Короткие чанки с умеренным словом заполняют и 1024, и 4096, и вытесняют уже найденные строки. Рост File Recall куплен падением Changed Line Recall. По правилу задачи это не успех.

### 3. Вставка длинного имени после первой тысячи токенов v0.4

Конфиг `configs/pathpack_v09_splice.yaml`. Прогон `output/v09_splice_dev`. Оценка v0.4 не меняется. После чанков, которые заполняют первые 1024 токена, вставляются не больше двух функций. Берётся самый длинный идентификатор не короче 8 символов, который есть в запросе и принадлежит не больше чем 5 функциям. У каждой такой функции берётся один чанк с наибольшим lexical. Чанк, пересекающий уже уложенный якорь, пропускается.

При 1024 все четыре метрики совпали с v0.4 на всех 20 задачах. При 2048 и 4096:

| Метод | File | Function | Complete | Changed line | Latency, с |
| --- | ---: | ---: | ---: | ---: | ---: |
| pathpack-v4 | 0.725 | 0.202 | 0.091 | 0.148 | 0.605 |
| pathpack-v9 | 0.725 | 0.202 | 0.091 | 0.172 | 0.687 |

File, Function и Complete: 0/20, 0/18 и 0/18, разность ровно 0. Changed line +0.024, CI [0.000, 0.071], 1/13/0. Единственная задача `astropy__astropy-8707`, 0→0.333. Покрытие золотых функций не сдвинулось ни на одной задаче: добавленная строка не входит в тело, по которому считается Function Recall. Интервал включает 0. Та же картина, что у v0.6 и v0.8.

Офлайн-ранжирование до прогона объясняет, почему файлы не приехали. При пороге длины 8 и частоте ≤ 5 золотой файл оказывается первым только там, где в задаче есть длинное уникальное имя (`fromstring`, `collectfactoranddimension`, `userequiredattribute`). В остальных задачах длиннее оказываются чужие имена (`description`, `dependencies`, `distributed`). Один такой чанк после якоря не вытесняет файлы v0.4 и не дотягивает тело функции до 20%.

## Что из этого следует

Бюджет 2048 уже занят открывающими чанками. Чтобы добавить пропущенный файл, нужно либо укоротить эти чанки, либо выкинуть часть из них. Укорочение опасно: строки и функции, которые v0.4 вообще находит, лежат в первой тысяче токенов. Выкидывание в эксперименте 2 поднимает File Recall до 0.950 и роняет Changed Line Recall до 0.095. Оставить первую тысячу и вставить только длинное редкое имя сохраняет три метрики и добавляет строки на одной задаче, без статистического отделения от нуля.

Не запускался четвёртый прогон с большим числом вставленных чанков одной функции. Офлайн-список имён показывает, что лишний бюджет чаще займёт чужой файл (`description`, `dependencies`), а прокси покрытия по номерам строк уже завысил выигрыш sympy относительно официального скорера. Подбирать длину, частоту и число вставок по этим 20 задачам после просмотра чисел нельзя: конфиги выше зафиксированы.

v0.4 остаётся основной версией. Целевые 0.800 / 0.280 / 0.150 / 0.220 не получены. Статистически убедительного выигрыша сразу по всем четырём метрикам нет.
