# Объединение v0.2 и v0.3 — 1 ноября 2026

Рабочая версия находится в корне текущего проекта. Имя папки оставлено прежним,
поскольку `.venv` и Git worktrees содержат абсолютные пути. Пакет имеет версию 0.3.0.

Из v0.3 перенесены `pathpack-v3`, `audit.py`, `function_gold.py`, scorer с функциями,
CLI-команды `audit` и `gold-functions`, dev-скрипт, тесты и исходные материалы отчёта.
Из текущей копии сохранены `redundancy_penalty`, локальное окружение, snapshots,
манифесты, кеш Hugging Face и предыдущие результаты. Алгоритм legacy PathPack
при нулевом штрафе сохранён; v3 выбирается отдельным именем метода.

Основной файл — [03_swebench_pathpack.ipynb](../notebooks/03_swebench_pathpack.ipynb).
В него включены четыре метода, изменённые строки → функции, аудит, bootstrap,
исторические таблицы и визуализации из v0.3. Новый вывод направляется в
`output/benchmark/v03/`; существующие predictions и таблицы не перезаписывались.
Абляции исследуют legacy PathPack, отдельно от нового алгоритма.

Function gold изменился: v0.2 размечал функции по всему диапазону hunk, а v0.3 —
по изменённым старым строкам. Новые метрики получают отдельные файлы и описание
метода разметки. Уже просмотренная test-выборка отмечена как ретроспективная.
По умолчанию запускается dev; для утверждения об обобщении нужен новый holdout.

Исходные версии изменяемых файлов и журнал переноса сохранены в
`reports/merge_v03_backup/` (папка удалена из рабочего дерева; версии доступны в истории git, коммит `650744b`). Исходный аудит-блокнот сохранён как исторический;
для продолжения работы используйте единый основной блокнот и перезапустите kernel.
