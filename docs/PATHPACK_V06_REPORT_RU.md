# PathPack v0.6: интеграция и проверка на dev

Дата: 2 ноября 2026. Прототип в блокноте `notebooks/07_pathpack_v06.ipynb` вызывал `make_v6_chunks` и `retrieve(..., method='pathpack-v6')` и был исполнен на более раннем дереве проекта. Отдельного архива с исходниками v0.6 в рабочей копии не было. Алгоритм перенесён на текущие интерфейсы: AST-чанки, префиксная упаковка и счётчик `utf8_bytes_div4_ceil_serialized_context_v1`. v0.4, v0.5 и v0.5.1 этой переносом не менялись.

Конфигурация `configs/pathpack_v06.yaml` зафиксирована до прогона и после него не подбиралась.

## Что делает v0.6

Целая функция даёт prior и зёрна графа. В контекст попадает AST-срез этой функции, а не автоматически её первый чанк. Файл не отсекается потолком Top-K. Оценка среза:

`0.50·локальный BM25 + 0.15·имя + 0.20·prior функции + 0.15·граф`

Граф — лучший путь не длиннее 3 переходов, веса рёбер `calls 1.0`, `inherits 0.65`, `imports 0.45`, `defines 0.22`, затухание 0.8. Зерно своего графового бонуса не получает. Diversity уменьшает повтор уже виденных слов и повтор слабого среза той же функции. Бонуса «первый чанк нового файла» нет.

Changed Line Recall hops 1, hops 2 и полного v0.6 совпал на всех 14 оцениваемых задачах. Глубина 3 не добавила покрытых строк относительно глубины 1. Граф поднимает Function Recall относительно варианта без графа: +0.111, ДИ [0.000, 0.278], 2 победы и 16 ничьих. На строках граф ничего не меняет.

Целые функции без нарезки дают Complete Function Recall 0.226, потому что выбранная функция попадает в контекст целиком. Интервал v0.6 минус этот вариант по Complete равен −0.167 и не включает 0: нарезка хуже по этой метрике. File Recall при этом 0.500, Changed Line Recall 0.148. При бюджете 4096 тот же вариант поднимает Changed Line Recall до 0.296 и File Recall до 0.675. Это наблюдение одного бюджета, конфиг v0.6 после него не менялся.

Prior целой функции снижает File Recall относительно варианта без него: 0.600 против 0.700, интервал разности включает 0. Даже без prior File Recall 0.700 остаётся ниже v0.4.

## Время запроса

Среднее по 20 задачам, индексация не входит: BM25 1.44 с, оценки срезов 0.57 с, diversity 0.37 с, граф 0.12 с, упаковка 0.01 с, всего 2.50 с. У v0.4 тот же прогон даёт 0.62 с. Узкое место — второй проход BM25 по целым функциям и по срезам на больших репозиториях, в первую очередь SymPy. Отдельная переписка этого прохода не делалась: она не меняет вывод о качестве.

## Что не проверялось

Holdout `output/v05_holdout` не оценивался. v0.6 не обошёл v0.4 с интервалом, исключающим 0, а снимки holdout не развёрнуты. Embedding по-прежнему `not_run`. Счётчик токенов не заменялся токенизатором Gemma.

Основной версией остаётся PathPack v0.4.
